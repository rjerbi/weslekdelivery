# Weslek - Laravel Delivery Website

Weslek is a Laravel-based food delivery application that allows customers to place orders and view the availability of couriers in real-time.

## Features

- Restaurant pages with menus.
- Reservation form (name, email, phone, date, time, orders, special message).
- Couriers list with status: available / delivering.
- Interactive light and dark mode.
- Success notifications and error handling.

## Installation and project running

- composer install
- php artisan key:generate
- php artisan migrate
- php artisan serve
